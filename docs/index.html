化龙镇中心幼儿园电子资源平台 Hualong Kindergarten Electronic Resource Platform

一个为园所管理者、教师与家长服务的电子资源平台，统一管理园所资源、教研培训、党建与家园社共育。 本仓库不是成品应用，而是它的规格说明、设计系统与质量门禁——为后续开发打下可验证的基础。
An electronic resource platform for kindergarten managers, teachers, and parents. This repository is not the shipped app; it holds the platform’s specification, design system, and quality harness — a verifiable foundation the product is built on.

平台模块

模块Modules

平台由八个核心模块组成；家长端只呈现家园社共育相关内容，不展示教师端模块。 Eight core modules; the parent client surfaces only home-school-community co-education content.

  • 首页 Home

    各端入口页，聚合待办事项、资源中心通知、常用入口与推荐课程案例；按端口显示不同内容。

    Per-role landing page: to-do items, resource-center notices, quick entries, recommended cases.

  • 党建管理 Party-building

    党建学习、党建活动、品牌建设三类资料的呈现；以查看为主，上传建议放 PC 后台。

    Party-building study, activities, and brand-building; view-first, with uploads via the PC backend.

  • 综合协调 Administrative coordination

    行政统筹、后勤保障、人事管理三类文件资料；手机端查看为主，PC 端上传为主。

    Administrative planning, logistics, and HR documents; mobile is view-first, PC is upload-first.

  • 教研培训 Teaching-research and training

    课程建设、课程库+资源库、教研研修；1.0 重点为课程资源、教研资料与评价五维图。

    Curriculum development, the libraries, and teaching-research study; v1.0 focuses on course resources.

  • 资源库 + 案例库 Resource & Case libraries

    资源按“衣/食/住/行/艺”分类；案例库（又称课程库）按年级、五大领域、活动形式与资源标签筛选。

    Resources by clothing/food/housing/travel/arts; the case library filtered by grade, domains, form, tag.

  • 家园社共育 Home-school-community co-education

    在园时光、亲子任务（含社区教育）、成长档案、成长册四大块。

    Garden moments, parent-child tasks (incl. community education), growth records, and growth books.

  • 家长端 Parent client

    家长使用的端口，只保留家园社共育相关内容；不展示党建、综合协调、教研培训等教师端模块。

    The parent interface; surfaces co-education content only — never teacher-side modules.

  • PC 后台 PC backend

    桌面端管理后台，承担文件类资料上传与批量管理；手机端用于高频轻量操作。

    Desktop backend for file-heavy uploads and bulk management; mobile handles lightweight actions.

三端角色

角色Roles

同一平台依角色呈现不同内容与权限。One platform; content and permissions differ by role.

  • 管理端 · Admin client

    园所管理者 Manager

    负责审核、发布共建任务、内容与用户管理；审核通过进入资源库/案例库，驳回须填写原因退回。

    Audits, publishes co-construction tasks, manages content and users across the three clients.

  • 教师端 · Teacher client

    教师 Teacher

    上传资源与案例、完成任务、发布在园时光与评价，并生成成长档案与成长册。

    Uploads resources/cases, completes tasks, publishes garden moments, and builds growth records.

  • 家长端 · Parent client

    家长 Parent

    查看在园时光、完成亲子任务、阅读评价与成长册；仅可见家园社共育相关内容。

    Views garden moments, completes parent-child tasks, reads evaluations — co-education content only.

不可妥协

合规Compliance

面向幼儿与家长的平台，合规是上线前提，非可选项。For a platform serving children and parents, compliance is a precondition for launch — not optional.

强制要求 · MANDATORY
  • 内容安全 · Content moderation. 所有用户生成内容（文本、图片、视频、音频、昵称头像）须经 security.msgSecCheck / security.mediaCheckAsync 校验，未实现即审核不通过。 Every UGC item must pass WeChat content security checks; omitting it fails platform review.
  • 小程序备案 · ICP filing. 自 2023-09-01 起强制：上线前完成工信部备案（含 12381 短信核验）。 Mandatory since 2023-09-01: complete MIIT filing (with 12381 SMS verification) before go-live.
  • 未成年人数据 · Minors’ data. 幼儿照片等敏感信息须监护人明示同意、隐私政策弹窗、数据最小化与严格访问控制（依据 PIPL 与未成年人网络保护条例）。 Children’s sensitive data requires explicit guardian consent, a privacy popup, data minimization, and strict access control.
