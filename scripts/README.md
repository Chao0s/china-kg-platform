# scripts/ — Launchers

## Launch the knowledge graph / 启动知识图谱

Open the interactive **Understand-Anything** dashboard for this repo's committed map
(`.understand-anything/knowledge-graph.json`). For anyone who clones the repo.

| Platform | Command |
|---|---|
| Windows | double-click `scripts\launch-knowledge-graph.bat` (or run it in a terminal) |
| macOS / Linux / git-bash | `./scripts/launch-knowledge-graph.sh` |
| Any (npm) | `npm run graph` |

All three call `scripts/launch-knowledge-graph.mjs`, which:
1. checks the map exists (else tells you to run `/understand-anything:understand`);
2. locates the understand-anything plugin's dashboard (or honors `UA_PLUGIN_ROOT`);
3. ensures **pnpm** (via corepack, else `npm i -g pnpm`);
4. installs dashboard deps + builds the core package (+ rebuilds esbuild for Vite);
5. starts Vite and prints the tokenized URL, e.g. `http://127.0.0.1:5173/?token=…`.

**Open the printed URL including the `?token=…`** — without the token the dashboard shows an access gate.
Press `Ctrl+C` to stop the server.

### Requirements
- **Node.js >= 18** on PATH.
- The **understand-anything** Claude Code plugin installed (provides the dashboard). If it lives somewhere
  non-standard, set `UA_PLUGIN_ROOT` to the plugin root that contains `packages/dashboard`.

### Regenerating the map
The map is generated by Claude Code, not by this script:
```
/understand-anything:understand
```
That writes `.understand-anything/knowledge-graph.json` (the one file under `.understand-anything/` that is
tracked in git and shared). Re-run it after significant code changes; the gate's `understandMap` reminder
nudges you when it is missing.
